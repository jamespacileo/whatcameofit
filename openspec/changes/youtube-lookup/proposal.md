# YouTube lookup in the extension

Readers encounter medical claims in videos as well as articles and social images. The generic page reader can include YouTube comments and recommendations, while watch/share/Shorts URLs currently produce different comparison keys.

Read the current video's title, description, source links and captions/transcript already loaded in its page. Scope screenshot fallback to that video's visible frame. Preserve automatic lookup on popup opening, selection-only searches, consent, private result reuse and the existing spending controls. Do not fetch YouTube from the service or add audio transcription.

This is a subsequent extension change; it does not replace the installed Safari app or the Apple submission already waiting for review.
