# Which outlets can be read

Checked 2026-11-16 with `thenwhat outlets`, over every tracked article. Regenerate it with that command; do not edit it by hand.

- Every article was asked of the page reader, which decides how each site is asked.
- **Read:** the reader gave enough main text, a headline and a publication date. **Thin:** the main text was too short to read. **No date:** enough text, but no headline or no publication date the pipeline can read, so a lead's read refuses it.
- **Refused:** the reader answered that the address is not allowed. **Failed:** the page did not come back, by the site's HTTP status, or *not now* when the reader said the site could not be asked yet.
- The signal columns count the pages that carried each thing a lookup uses.
