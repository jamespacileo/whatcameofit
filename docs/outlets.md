# Which outlets can be read

Checked 2026-11-12 with `thenwhat outlets`, over every tracked article. Regenerate it with that command; do not edit it by hand.

- **Read:** the site served the article. **Thin:** it served a page with too little text to read, usually because scripts draw the article.
- **Refused:** the site's robots.txt forbids the fetch, or could not be read, so the article was not asked for. **Failed:** the page did not come back, by HTTP status.
- The signal columns count the pages that carried each thing a lookup uses.
- **Lookups:** articles read whose claim has approved trials. **Trial found:** an approved trial was among the likely records. **Trial first:** it was listed first.
